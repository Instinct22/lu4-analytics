Command .lock — protecting your character

Masterwork 25.06.2025

Basics

To increase the safety of your character, we developed a .lock command, which prohibits the transfer of any items until the character is unlocked. Now, if necessary, you can entrust your character to another person without worrying about the valuables.

Not available when protection is enabled:

  • Throwing items on the ground
  • Placing items in any warehouse
  • Getting items from any warehouse
  • Transfer items to another character via trade
  • Buying or selling items by private store
  • Creating items in the workshop
  • Opening a private store to buy or sell items
  • Attacking a non-flagged character in a normal zone

Available when protection is enabled:

  • Picking-up items
  • Opening a workshop to create items
  • Attacking a character in the combat zone

How to use?

Set up password

To start using the .lock command you need to set a password, which must contain from 4 to 8 characters.

To set a password, enter the ".setlockpw password" command into the chat. For example: .setlockpw 1234, if your password is 1234.

Pay attention!

Don't tell anyone your password! In case valuables had been stolen due to the password transfer to third parties, items can not be returned.

Keep your password in a safe place. If you lose your password, it can be restored via Support. Paid service.

Lock character

Before transferring access to third parties, enable lock by the command "".lock password". For example: .lock 1234, if your password is 1234.

Unlock character

To unlock a character, use the command "".unlock password". For example: .unlock 1234, if your password is 1234.
